# Lottus Services Inc. — 2026 Digital Rebrand

## Positioning
The corporate website presents Lottus as a **Digital Systems & Web Development** company focused on public digital experiences, business portals, operational systems and integrations/automation.

## Premium capability iteration — September 19, 2026

This release moves the site from a portfolio overview to a premium, capability-led technology presentation.

### Public experience changes
- Rebuilt the Home with a deep-navy / electric-blue / cyan / white visual system intended to communicate trust, technical competence, clarity and premium positioning.
- Replaced the former dark-background logo treatment with a new transparent Lottus brand asset and created a white-background brand plate for controlled use.
- Added complete favicon / mobile-icon coverage and an Open Graph social image.
- Removed public GitHub links and public GitHub references from the main Lottus customer-facing pages. Repository access remains an internal development concern.
- Added four dedicated capability pages:
  - `capability-websites.html`
  - `capability-portals.html`
  - `capability-systems.html`
  - `capability-integrations.html`
- Each capability page explains scope, workflow thinking, security / data considerations, demonstrated examples and reasonable expansion potential.
- Added original lightweight MP4 motion assets for the Home and portfolio. They contain no client data and do not depend on external video hosting.
- Rebuilt the technical portfolio around public evidence and live experiences rather than repository access.
- Preserved existing project subfolders and the Stripe checkout function contract.

### Brand / color direction
The visual system uses:
- deep navy / near-black for authority, stability and technical depth;
- electric blue as the primary technology and action color;
- cyan for system status, precision and innovation cues;
- white / cool neutrals for clarity, contrast and trust;
- limited violet only as a secondary sophistication accent.

### Security / disclosure rule
Public pages describe capabilities without exposing credentials, private administrator routes, service-role keys, API secrets or repository access.

Upload the entire repository contents to the existing Lottus repository root. Netlify can continue deploying the project from the same site configuration.
