# Lottus Services Inc. — 2026 Digital Rebrand

## New positioning
The root website now presents Lottus as a **Digital Systems & Web Development** company rather than a hauling / dump-trailer operation.

## What changed
- Replaced the former hauling, equipment, landscaping and jobsite-support homepage.
- New corporate technology positioning with a modern responsive design.
- Added clear capability areas: web experiences, business portals, operational systems, integrations and automation.
- Added platform/system portfolio: PLEASE, CAL, Integrity Concrete Solutions and KineticaPlus.
- Added selected live development work already present in this repository: SumaQ on 17th, Groupe VGC, RB Moving, ONTA, JP Painting and Drilling & Well Engineering.
- Kept existing project folders and routes unchanged.
- Restyled the existing Stripe payment flow to match the new corporate brand without changing the checkout function contract.
- Updated metadata and PWA manifest.

## Deployment note
The root files (`index.html`, `style.css`, `app.js`, `manifest.json`, `payment.html`, `payment-success.html`) are the new Lottus corporate experience. Existing subfolders remain independent project builds.

## Legacy assets
Old truck / trailer image files are no longer used by the website and can be removed permanently after deployment validation.
