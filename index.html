SECURITY PATTERN

Secrets stay server-side.

Service-role keys and payment secrets are kept in deployment environment variables and server functions rather than exposed in browser code.

DATA PATTERN

Use the database as source of truth.

Where shared production data matters, Supabase/PostgreSQL replaces local-only browser storage and adds role-based policies and auditable records.

GROWTH PATTERN

Build modularly.

Authentication, scheduling, invoicing, reporting, provider management and other proven modules can be adapted to new businesses without rebuilding every concept from zero.
