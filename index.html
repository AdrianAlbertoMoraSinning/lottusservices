Frequently asked questions

Useful questions before we scope a project.

Can a project start with only a website?

Yes. A public website can be delivered as a focused project and later connect to booking, customer accounts, payments, portals or internal workflows if needed.

Can Lottus work with an existing process or system?

Yes. Discovery begins with the workflow you already use so we can identify what should remain, what should change and what can be integrated.

Who owns access to the deployed system?

Access, hosting, data custody, licensing and handoff are defined in the project scope so responsibilities are clear before launch.

Are integrations included automatically?

No. Payments, email, APIs and other third-party services are included when they are part of the agreed scope and supported by the selected provider.

What happens after launch?

Support, maintenance and future improvements are agreed as part of the project rather than assumed to be unlimited.
